# What I Do Today


## A. Remplir une monture de raid
### Trouver ID de la monture
1. Nom de la monture a taper sur internet  
2. Choisir le lien Wowhead avec [nom de la monture] - objet - World of warcraft  
3. Descendre sur l'onglet Enseigne et cliquer sur le nom de la monture  
4. Prendre l'ID de la monture renseigner sur le panneau de droite  

### Trouver ID de l'instance
1. Aller sur le [site instance ID](https://wowpedia.fandom.com/wiki/InstanceID) 
2. Taper le nom de l'instance en anglais
3. Recupéré l'ID

### Trouver ID donjon
1. Aller sur le [site donjon ID](https://wowpedia.fandom.com/wiki/LfgDungeonID) 
2. Taper le nom de l'instance en anglais
3. Recupéré l'ID
